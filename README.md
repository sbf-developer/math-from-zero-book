# Mathematics From Zero

**Mathematics From Zero** is a visual roadmap through the central ideas of mathematics: quantity, algebra, geometry, change, uncertainty, data, proof, computation, and abstraction.

The book is designed to be read from the beginning, but its map is a network rather than a rigid staircase. Each topic starts with a picture or mental model, then introduces notation and connections.

## Files

- `math-from-zero-visual.pdf` - the compiled book
- `math-from-zero-visual.tex` - the complete LaTeX source

## Build

Run:

```sh
make
```

The build uses `pdflatex` and runs twice so the table of contents and bookmarks settle correctly.
